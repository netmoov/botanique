# Sources des photographies — V5

- 61 photographies sont épinglées directement vers Wikimedia Commons.
- 97 cartes supplémentaires utilisent une résolution automatique Wikimedia Commons à partir d’une requête botanique contrôlée stockée dans `imageLookup`.
- La page source/licence est accessible depuis la photo et depuis la fiche complète.
- Les résultats résolus sont mis en cache localement dans le navigateur sous `ifapmeBotaniqueImageCacheV2`.
- Pour les entrées génériques, hybrides ou de cultivar lorsque le référentiel n’identifie pas une espèce photographique unique, l’interface affiche explicitement une mention de type « illustration représentative ».

Cette stratégie évite d’inventer une photo et distingue une correspondance exacte d’une illustration représentative.
