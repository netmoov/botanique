# Floreview V8

Modifications :
- la marque affichée devient Floreview ;
- l'ancienne organisation par codes et statuts n'est plus affichée ni utilisée ;
- tous les végétaux restent dans la collection, y compris ceux qui étaient auparavant optionnels ;
- trois catégories de révision sont disponibles : Fleurs coupées, Plantes et Feuillage ;
- les anciennes mentions sont filtrées des sources et notes visibles ;
- la progression compte désormais toute la collection ;
- l'affichage mobile compact est conservé.

Répartition actuelle :
- 83 fleurs coupées
- 24 plantes
- 51 feuillages
- 158 végétaux au total

Fichiers à téléverser :
- index.html
- app.js
- mobile-compact.css
- data/floreview-families.js
- data/floreview-categories.js

Ne pas supprimer :
- data/plants.js
- assets/images/

Remarque :
les clés de progression locale ont été renommées pour Floreview. La progression locale de l'ancienne version n'est donc pas reprise automatiquement.
